# 🌾 Node Farm Project

A basic Node.js web application that dynamically generates product pages using raw Node.js without any frameworks.

---

# 🚀 How to Set Up and Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/n-ananya/node-farm.git
   cd node-farm



2.Install Node.js
Download and install Node.js from https://nodejs.org

3.Run the app
node server.js

4.Open your browser and navigate to:
http://localhost:8000


🧩 Dependencies & Configuration
Node.js (v14 or higher)
Install Dependencies: npm install slugify
